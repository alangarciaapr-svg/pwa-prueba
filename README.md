## Publicar
1. Sube todos los archivos a la raíz de un repositorio GitHub.
2. Ve a Settings > Pages.
3. Elige Deploy from a branch.
4. Selecciona main y /(root).
5. Guarda.

La app incluye manifest, service worker e iconos para funcionamiento como PWA.
